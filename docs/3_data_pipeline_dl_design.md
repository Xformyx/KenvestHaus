# 3. 데이터 파이프라인 및 딥러닝 학습 구조 설계

주식 자동매매 시스템의 성능은 양질의 데이터와 이를 바탕으로 한 지속적인 학습에 달려있습니다. 이 문서에서는 데이터를 수집하여 백테스팅 및 모의투자를 거쳐 딥러닝 모델을 학습시키는 전체 파이프라인을 설계합니다.

## 3.1 데이터 수집 및 전처리 파이프라인

성공적인 딥러닝 모델 학습을 위해서는 다양한 출처의 데이터를 정형화하여 시계열 데이터베이스에 저장하는 과정이 필수적입니다.

| 데이터 유형 | 수집 출처 | 전처리 및 저장 방식 |
| :--- | :--- | :--- |
| **가격 및 거래량 (OHLCV)** | 한국투자증권 OpenAPI, Yahoo Finance | 결측치 보간(Interpolation), 액면분할/병합 등 수정주가 반영 후 InfluxDB 저장 |
| **수급 데이터** | KRX 정보 데이터 시스템, 증권사 API | 외국인/기관/개인 순매수 대금 정규화(Normalization) 및 이동평균 산출 |
| **재무 데이터** | DART OpenAPI, 에프앤가이드(FnGuide) | 분기별 재무제표 파싱, 주요 비율(PER, PBR, ROE) 계산 후 PostgreSQL 저장 |
| **뉴스 및 공시 (텍스트)** | 네이버 금융 뉴스 크롤링, DART | KoBERT 등 NLP 모델을 활용한 감성 점수(Sentiment Score: -1 ~ 1) 추출 후 시계열 데이터와 병합 |

## 3.2 3단계 검증 및 시뮬레이션 프로세스

단순히 현재 시그널만 보고 매매하는 것을 방지하기 위해, 모든 매매 전략과 딥러닝 모델은 다음의 3단계 검증을 통과해야만 실제 계좌에 적용됩니다.

### 1단계: 과거 데이터 백테스팅 (Historical Backtesting)
과거 5~10년간의 데이터를 바탕으로 설정된 매매 기법들의 성과를 시뮬레이션합니다. 슬리피지(Slippage)와 거래 수수료, 세금을 엄격하게 반영하여 현실적인 수익률(CAGR)과 최대 낙폭(MDD), 승률을 계산합니다. 백테스팅 결과는 Web UI를 통해 상세한 리포트 형태로 제공됩니다.

### 2단계: 모의투자 (Paper Trading)
백테스팅에서 검증된 전략을 실시간 시장 데이터에 연동하여 가상의 자금으로 매매를 진행합니다. 과거 데이터에는 나타나지 않는 실시간 호가창의 변화, 체결 지연 등의 변수를 확인하며 전략의 안정성을 최종 점검합니다. 최소 2~4주간의 모의투자 기간을 거치는 것을 권장합니다.

### 3단계: 실전 자동매매 (Live Trading)
모의투자에서도 안정적인 수익 모델임이 입증되면, 사용자의 승인 하에 실제 한국투자증권 계좌를 통해 자동매매를 시작합니다.

## 3.3 딥러닝 학습 아키텍처

기존의 정해진 규칙(Rule-based)에 의한 매매 시그널은 시장 상황 변화에 취약할 수 있습니다. 이를 보완하기 위해 과거 데이터와 시그널 성과를 바탕으로 최적의 결정을 내리는 딥러닝 모델을 구축합니다.

### 딥러닝 모델 구성
모델은 시계열 데이터의 패턴 인식에 뛰어난 **LSTM(Long Short-Term Memory)** 또는 최근 자연어 처리 및 시계열 예측에서 우수한 성능을 보이는 **Transformer** 아키텍처를 기반으로 합니다.

| 학습 요소 | 설명 |
| :--- | :--- |
| **입력 데이터 (Features)** | 과거 N일간의 OHLCV, 기술적 지표(RSI, MACD 등), 수급 데이터, 뉴스 감성 점수, 차트 분석 Agent의 시그널 발생 여부 |
| **목표 변수 (Labels)** | 시그널 발생 후 일정 기간(예: 5일, 20일) 내의 최대 수익률 도달 여부 또는 특정 수익률 이상 달성 여부 (Classification/Regression) |
| **강화학습 (RL) 적용** | 매수/매도/관망 액션에 대한 보상(수익)과 페널티(손실, 과도한 거래 비용)를 부여하여, 장기적 수익을 극대화하는 정책(Policy) 학습 |

### 지속적 학습 (Continuous Learning) 파이프라인
시장은 끊임없이 변하므로 모델도 지속적으로 진화해야 합니다.
1. **데이터 축적:** 실전 매매 및 모의투자에서 발생한 모든 매매 기록, 시그널 적중 여부, 당시의 시장 데이터를 Database에 저장합니다.
2. **주기적 재학습:** 주말이나 장 마감 후, 새로 축적된 데이터를 포함하여 모델의 가중치(Weights)를 미세 조정(Fine-tuning)합니다.
3. **모델 평가 및 교체 (A/B 테스트):** 새로 학습된 모델(Champion)과 기존 모델(Challenger)의 성과를 모의투자 환경에서 비교하여, 더 나은 성과를 보이는 모델로 자동 업데이트합니다.
