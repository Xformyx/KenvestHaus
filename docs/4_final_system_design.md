# 주식 종목 추천 및 자동매매 시스템 최종 설계 문서

본 문서는 사용자의 요구사항과 실제 텔레그램 메시지 데이터를 분석하여 도출된 주식 종목 추천 및 자동매매 시스템의 최종 아키텍처 및 세부 설계안입니다. 

## 1. 시스템 전체 아키텍처 (System Architecture)

전체 시스템은 **데이터 수집 파이프라인**, **Multi-Agent 분석 엔진**, **자동매매 실행 엔진**, 그리고 **Web UI 및 알림 시스템**으로 구성됩니다.

### 1.1 데이터 수집 및 처리
*   **실시간/시계열 데이터:** 한국투자증권 OpenAPI를 통한 체결강도, 거래대금, 호가, OHLCV 데이터 수집. (InfluxDB 저장)
*   **수급 데이터:** KRX 및 증권사 API를 통한 스마트머니(외국인/기관) 및 개인 순매수 데이터 수집.
*   **매크로/글로벌 데이터:** 미국 주요 지수(다우, S&P, 나스닥) 및 주요 종목(SOXX, NVDA 등) 마감 데이터 수집을 통해 한국 시장 동조화(Coupling) 예측.
*   **텍스트 데이터:** 뉴스, 공시, 테마 정보 크롤링 및 NLP 감성 분석.

### 1.2 핵심 Multi-Agent 시스템
시스템은 4개의 전문화된 Agent로 구성되어 상호 협력합니다.

1.  **기업/테마 분석 Agent (Fundamental & Theme Agent):**
    *   실시간으로 돈이 몰리는 '강세 테마'를 식별하고 주도주를 필터링합니다. (예: 반도체, 전력, 신규상장 등)
    *   글로벌 매크로 지표(미국 증시)를 분석하여 당일 한국 시장의 수혜 섹터를 예측합니다.
2.  **차트/수급 분석 Agent (Technical & Flow Agent):**
    *   실시간 체결강도, 거래대금 급증, 5분봉 골든크로스(GC) 등을 감시하여 타점을 잡습니다.
    *   외국인/기관(스마트머니)의 매수 전환(Sell → Buy) 등 수급 이상 신호를 포착합니다.
3.  **딥러닝/의사결정 Agent (AI & Strategy Agent):**
    *   베이지안(Bayesian) 확률 모델을 기반으로 시그널의 신뢰도(예: 38%, 88%)를 계산합니다.
    *   현재의 시장 체제(Market Regime, 예: 변동성 장, 좋은 장)를 판단하고, 4중 필터를 통해 최종 매매 적합성 점수(예: 80점 STRONG_BUY)를 산출합니다.
    *   앙상블 모델(Stacked Generalization) 및 포트폴리오 이론(Markowitz)을 적용하여 자산을 배분합니다.
4.  **자동매매 Agent (Execution Agent):**
    *   한국투자증권 API를 통해 주문을 실행합니다.
    *   Lopez de Prado의 Triple-Barrier Method(익절, 손절, 시간 한계)를 적용하여 리스크를 엄격하게 관리합니다.

## 2. 텔레그램 데이터 기반 추론 및 적용 기법

제공해주신 9가지 텔레그램 메시지와 매거진 데이터를 분석한 결과, 시스템에 이미 고도화된 계량 금융(Quant) 및 머신러닝 기법들이 적용되어 있음을 확인했습니다. 이를 본 설계에 모두 반영했습니다.

### 2.1 주요 매매 전략 및 지표 (UI 선택 항목)

| 분류 | 기법 및 지표 | 설명 및 적용 방안 |
| :--- | :--- | :--- |
| **단기 (단타)** | **골든존 (Golden Zone)** | 당일 상승률 +5% ~ +13% 구간에 진입한 종목을 추종 매수. 당일 모멘텀이 가장 강한 구간. |
| | **5분봉 GC / DC** | 5분봉 기준 이동평균선 골든크로스(매수) 및 데드크로스(매도/손절) 활용. |
| | **체결강도 & 거래대금** | 체결강도 100 이상(매수세 우위), 평소 대비 거래량 3배 이상 급증 시 진입. 체결강도 하락 시 청산. |
| | **상한가 갭상 베팅** | 상한가 근접 종목은 추격 매수를 자제하고, 종가 무렵 매수하여 익일 시초가 갭상승(+1~3%) 시 매도. |
| **중장기** | **거북이 매매 (Turtle Trading)** | 20일 이동평균선 돌파 등 중장기 추세 추종 전략. 신뢰도가 높은 종목을 1~3개월 보유. |
| **수급/테마** | **스마트머니 추적** | 외국인, 기관(투신, 금융투자)의 매수 전환(Sell → Buy) 포착. |
| | **글로벌 동조화 (Coupling)** | 전일 미국 시장(SOXX, NVDA, TSLA 등)의 강세 테마를 분석하여 당일 한국 시장의 관련 테마(반도체, 2차전지 등) 선취매. |

### 2.2 AI 및 리스크 관리 알고리즘 (백엔드 탑재)

1.  **베이지안 신뢰도 (Bayesian Confidence):** 단순 과거 승률이 아닌, 사전 확률과 새로운 증거(현재 시그널)를 결합하여 해당 타점의 성공 확률(신뢰도)을 %로 산출합니다.
2.  **Triple-Barrier Method (Lopez de Prado, 2018):** 포지션 청산을 위한 3가지 장벽을 설정합니다.
    *   상단 장벽: 목표 수익률 (익절, Take-Profit)
    *   하단 장벽: 최대 허용 손실 (손절, Stop-Loss)
    *   시간 장벽: 목표 시간 초과 시 무조건 청산 (Time-Limit, 예: 보유 10110분 초과 시 재평가)
3.  **시장 체제 인식 (Market Regime Detection):** 현재 시장이 '변동성 장'인지 '좋은 장(안정)'인지 VIX 추정치 등을 통해 판단하여, 공격적 진입 또는 보수적 방어(성격 모드)로 시스템 상태를 전환합니다.
4.  **포트폴리오 최적화 (Markowitz, 1952):** 다수의 종목에 분산 투자할 때 리스크 대비 수익을 극대화하는 비중을 계산합니다.

## 3. 사용자 인터페이스 (Web UI) 및 알림

### 3.1 Web UI Dashboard
*   **포트폴리오 관리:** 한국투자증권(자동매매) 및 토스증권(스크래핑 조회) 연동을 통한 통합 잔고 및 손익(OBI 지표 등) 확인.
*   **전략 설정 (Settings):** 단기/중기 투자 비중 설정, 위 2.1항의 매매 기법별 Check/Uncheck 활성화 기능.
*   **백테스팅 리포트:** 딥러닝 학습 결과(승률, 누적 수익률, 청산 건수) 및 진화값 시각화.

### 3.2 텔레그램 알림 시스템 (Telegram Bot)
분석된 데이터와 동일한 형태의 실시간 알림을 제공합니다.
1.  **장전 (08:30):** 글로벌 마켓 요약, 미 자금 흐름에 따른 한국 수혜 테마, 데일리 매거진 발송.
2.  **장중 (09:00~15:20):** 단타 골든존 진입 신호, 상한가 임박 알림, 실시간 이상 수급/거래량 감지, 점심시간 중간 점검.
3.  **장마감 (15:30~):** 수급 스캔 결과, 내일 상승 여력 TOP3 종목, 마감 후 내일 전략 및 AI 학습 결과 브리핑.

## 4. 향후 개발 프로세스 제언

본 설계를 바탕으로 GitHub(`https://github.com/Xformyx/KenvestHaus`)에서 소스 관리를 진행하며, 다음 순서로 개발을 권장합니다.

1.  **Phase 1 (Data & Infrastructure):** 증권사 API 연동, DB 구축, 텔레그램 봇 껍데기 및 기본 크롤러 개발.
2.  **Phase 2 (Core Logic & AI):** 지표 계산 로직, 베이지안 신뢰도 모델, Triple-Barrier 청산 로직 구현.
3.  **Phase 3 (Web UI & Integration):** 사용자 설정 페이지 개발, 토스증권 연동, 전체 파이프라인 통합 테스트.
4.  **Phase 4 (Simulation & Live):** 과거 데이터 백테스팅, 모의투자 진행 후 실전 자동매매 전환.
