# 주식 종목 추천 및 자동매매 시스템 아키텍처 설계 초안

제안해주신 요구사항을 바탕으로 주식 종목 추천 및 자동매매 시스템의 전체 아키텍처 초안을 구성해 보았습니다. 이 문서는 본격적인 개발에 앞서 시스템의 큰 그림을 그리고 방향성을 맞추기 위한 초안입니다.

## 1. 시스템 전체 아키텍처 (System Architecture)

전체 시스템은 크게 **데이터 수집/처리**, **Multi-Agent 기반 분석/판단**, **매매 실행 및 알림**, 그리고 **사용자 인터페이스(Web UI)** 로 나눌 수 있습니다.

### 1.1 데이터 파이프라인 (Data Pipeline)
*   **정형 데이터 (시세, 수급, 재무제표):** 증권사 API(한국투자증권 등) 및 공공데이터포털, KRX 정보 데이터 시스템 활용
*   **비정형 데이터 (뉴스, 공시):** DART OpenAPI(전자공시), 금융/경제 뉴스 크롤링
*   **데이터 저장소 (Database):** 
    *   시계열 데이터(틱/분/일봉 차트, 수급 데이터): InfluxDB 또는 TimescaleDB
    *   메타 데이터 및 재무제표, 사용자 정보: PostgreSQL / MySQL
    *   뉴스/공시 등 텍스트 데이터: MongoDB 또는 Elasticsearch

### 1.2 Multi-Agent 시스템 (핵심 분석 엔진)
각각의 특화된 Agent들이 독립적으로 데이터를 분석하고, 최종 의사결정 모델이 이를 종합하여 판단을 내립니다.

1.  **기업 분석 Agent (Fundamental Agent)**
    *   **역할:** 투자가치가 있는 저평가/성장 기업 발굴
    *   **분석 지표:** 재무제표(PER, PBR, ROE, 영업이익률 등), DART 공시 분석, 뉴스 센티멘털(감성) 분석 (NLP 적용)
2.  **차트 분석 Agent (Technical Agent)**
    *   **역할:** 기술적 지표 및 수급 기반의 단기/중기 매매 시그널 포착
    *   **분석 지표:** 
        *   가격/추세 지표: 이동평균선(MA), MACD, 볼린저밴드, 일목균형표, RSI, Stochastic 등
        *   수급 지표: 외국인/기관 순매수 동향, 거래량 회전율
        *   패턴 인식: 캔들 패턴, 지지/저항선 돌파 여부
3.  **딥러닝/의사결정 Agent (Deep Learning & Strategy Agent)**
    *   **역할:** 앞선 Agent들의 시그널과 과거 데이터를 바탕으로 최적의 매수/매도 타이밍 및 비중 결정
    *   **모델:** LSTM/Transformer 기반의 시계열 예측 모델, 강화학습(Reinforcement Learning)을 통한 매매 전략 최적화
4.  **자동매매 Agent (Execution Agent)**
    *   **역할:** 최종 매매 시그널을 바탕으로 실제 증권사 API를 호출하여 주문 실행
    *   **기능:** 지정가/시장가 주문, 분할 매수/매도, 손절/익절(Stop-Loss/Take-Profit) 라인 자동 감시

### 1.3 사용자 인터페이스 및 알림 (UI & Notification)
*   **Web UI Dashboard:** 
    *   보유 종목 현황 및 수익률 조회 (한국투자, 토스증권 연동)
    *   Agent들이 분석한 추천 종목 리스트 및 매매 시그널 발생 내역 확인
    *   백테스팅 및 모의투자 시뮬레이션 결과 리포트 제공
*   **Telegram Bot:** 
    *   실시간 매수/매도 시그널 발생 시 알림
    *   체결 내역 및 일일 수익률 브리핑 전송

## 2. 검증 및 고도화 프로세스 (Validation Process)

매매 시그널의 신뢰도를 높이기 위해 다음과 같은 3단계 검증 프로세스를 거칩니다.

1.  **과거 데이터 백테스팅 (Backtesting):** 유명한 매매 기법(돌파 매매, 눌림목 매매, 가치투자 등)을 과거 5~10년 데이터에 적용하여 승률, MDD(최대 낙폭), 수익률 시뮬레이션
2.  **모의투자 (Paper Trading):** 백테스팅에서 검증된 전략을 실시간 시장 데이터에 적용하여 가상의 자금으로 매매 진행 (실제 슬리피지 및 수수료 반영)
3.  **딥러닝 모델 학습 (Deep Learning Training):** 과거의 단순 시그널뿐만 아니라, 백테스팅 결과와 시장의 다양한 변수를 Feature로 삼아 AI 모델을 지속적으로 재학습

## 3. 논의가 필요한 사항 (Discussion Points)

설계를 구체화하기 위해 몇 가지 의견을 여쭙고 싶습니다.

1.  **투자 성향 및 타임프레임:** 단기(스윙, 데이트레이딩)와 중기(수주~수개월) 투자의 비중을 어느 정도로 생각하시나요? (예: 단기 30%, 중기 70%)
2.  **차트 분석 기법:** "유명한 기법들은 다 적용해보자"고 하셨는데, 평소 선호하시거나 특별히 성과가 좋았다고 생각하시는 지표나 기법(예: 볼린저밴드 돌파, MACD 다이버전스, 거래량 급증 등)이 있으신가요?
3.  **증권사 API:** 한국투자증권은 OpenAPI가 잘 되어 있어 자동매매 연동이 수월합니다. 다만, 토스증권의 경우 현재 공식적인 OpenAPI를 제공하지 않는 것으로 알고 있는데, 토스증권은 Web UI에서 보유 종목 조회(수동 입력 또는 스크래핑 방식) 용도로만 사용하고 실제 자동매매는 한국투자증권으로 진행하는 방향이 괜찮으실까요?
