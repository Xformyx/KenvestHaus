# 2. Agent별 세부 설계 및 매매 전략 목록

사용자의 피드백을 반영하여 각 Agent의 역할을 구체화하고, 시스템에 탑재될 다양한 매매 전략(기법)들을 정리했습니다. 이 전략들은 Web UI에서 사용자가 직접 활성화 여부를 결정할 수 있으며, 단기 및 중기 투자 비중 설정과 무관하게 종목 발굴 및 시그널 알림을 제공합니다.

## 2.1 기업 분석 Agent (Fundamental Agent)

기업 분석 Agent는 재무 데이터와 텍스트 데이터를 분석하여 '투자할 만한 가치가 있는 기업'을 필터링하는 역할을 수행합니다. 이 Agent는 주로 중기 투자 종목 발굴에 활용되지만, 단기 투자를 위한 최소한의 재무 건전성 필터링 역할도 함께 담당하여 리스크를 최소화합니다.

| UI 선택 항목 | 설명 | 주요 지표 |
| :--- | :--- | :--- |
| **저평가 가치주 발굴** | 시장에서 소외되었으나 내재가치가 높은 종목을 발굴합니다. 업종 평균 대비 저평가된 기업을 찾습니다. | PER, PBR, ROE |
| **성장주 발굴** | 최근 실적이 크게 개선되거나 고성장 산업에 속한 종목을 타겟으로 합니다. 실적 턴어라운드 기업을 찾습니다. | 매출액/영업이익 증가율, PEG |
| **재무 건전성 필터링** | 상장폐지나 유상증자 리스크가 있는 기업을 매매 대상에서 제외하는 필수적인 안전 장치입니다. | 부채비율, 유보율, 연속 적자 여부 |
| **공시/뉴스 센티멘털 분석** | 호재성 공시나 뉴스 기사의 긍정/부정 감성을 AI(NLP)가 분석하여 단기 매수 시그널에 가중치를 부여합니다. | DART 공시, 뉴스 텍스트 감성 점수 |

## 2.2 차트 분석 Agent (Technical Agent)

차트 분석 Agent는 가격, 거래량, 수급 데이터를 바탕으로 최적의 매수/매도 타이밍(시그널)을 포착합니다. 시스템은 널리 알려진 다양한 기술적 분석 기법들을 종합적으로 활용하며, 사용자는 UI를 통해 원하는 기법을 조합하여 사용할 수 있습니다.

### 추세 추종 및 돌파 전략 (단기/중기)

| UI 선택 항목 | 설명 |
| :--- | :--- |
| **이동평균선 골든크로스** | 단기 이평선이 장기 이평선을 상향 돌파할 때 매수하고, 데드크로스 발생 시 매도하여 추세의 초입을 잡는 기법입니다. |
| **볼린저 밴드 상단 돌파** | 밴드 폭이 좁아진 상태에서 주가가 거래량을 동반하며 상단 밴드를 돌파할 때, 강한 상승 추세로 판단하여 매수합니다. |
| **신고가/전고점 돌파** | 의미 있는 전고점 매물대나 52주 신고가를 대량의 거래량과 함께 돌파하는 종목을 추격 매수하는 강력한 모멘텀 전략입니다. |

### 역추세 및 눌림목 전략 (단기 스윙)

| UI 선택 항목 | 설명 |
| :--- | :--- |
| **볼린저 밴드 하단 반등** | 주가가 볼린저 밴드 하단에 닿거나 이탈한 후 다시 진입할 때, 단기 낙폭 과대에 따른 기술적 반등을 노리고 매수합니다. |
| **RSI 과매도 및 다이버전스** | RSI 지표가 과매도 구간(30 이하)에서 반등하거나, 주가 하락에도 RSI 저점이 높아지는 상승 다이버전스 발생 시 매수합니다. |
| **거래량 급증 후 눌림목** | 거래량이 평소 대비 크게 급증하며 장대양봉이 발생한 후, 며칠간 거래량이 급감하며 특정 지지선에서 지지받을 때 매수합니다. |

### 수급 추종 전략

| UI 선택 항목 | 설명 |
| :--- | :--- |
| **외국인/기관 양매수 추종** | 특정 기간 동안 외국인과 기관의 연속적인 순매수가 유입되는 종목을 따라 사며, 수급 주체의 평단가를 지지선으로 활용합니다. |

## 2.3 딥러닝/의사결정 Agent (Deep Learning & Strategy Agent)

의사결정 Agent는 단순 지표의 조합을 넘어, 과거 데이터를 학습한 AI 모델이 현재 상황의 승률을 예측하고 최종 매매 여부 및 비중을 결정하는 두뇌 역할을 합니다.

이 Agent는 차트 분석 Agent가 생성한 수많은 시그널 중, 과거 유사 패턴을 분석하여 승률이 낮은 '가짜 시그널(Fake Breakout)'을 걸러냅니다. 또한, 현재 시장 국면이 상승장인지 하락장인지 판단하여 공격적 매수 또는 보수적 현금 확보 스탠스를 결정합니다. 승률이 높게 예측되는 시그널에는 투자 비중을 늘리고, 불확실성이 높을 때는 비중을 줄이는 동적 비중 조절 기능도 수행합니다.

## 2.4 자동매매 Agent (Execution Agent)

자동매매 Agent는 의사결정 Agent의 명령을 받아 실제 증권사 API를 통해 빠르고 정확하게 주문을 실행하고 리스크를 관리합니다.

한국투자증권 OpenAPI를 통해 실시간 호가 조회 및 주문 전송을 수행하며, 토스증권은 포트폴리오 통합 조회를 위한 스크래핑 방식으로 연동됩니다. 리스크 관리를 위해 한 번에 전량 매수하지 않고 설정된 횟수에 따라 분할 매수/매도를 실행하며, 호가창 분석을 통해 슬리피지를 최소화합니다. 또한, 고점 대비 일정 비율 하락 시 수익을 실현하는 트레일링 스탑과, 매수 단가 대비 일정 비율 하락 시 기계적으로 손절하는 하드 스탑로스 기능을 통해 자산을 보호합니다.
